# Manual de usuario

1. Abra el enlace del asistente (PENDIENTE: URL publicada). Funciona en celular y computador.
2. Lea el saludo: **usted decide el diseño**; los de las publicaciones son inspiración.
3. Escriba su pregunta o toque una sugerencia. Verá «Escribiendo…» mientras responde.
4. Cada respuesta indica su **fuente** (de dónde sale el dato).
5. Si el asistente le muestra **Continuar por WhatsApp**, tóquelo: abrirá el chat con su pedido resumido.
6. Para empezar de cero use **Nueva conversación**.

## Límites conocidos
- No confirma stock ni medios de pago: lo hace una persona por WhatsApp.
- Cotiza solo 1 o 2 camisas; desde 3 lo atiende una persona.
- No recibe archivos: el diseño se envía por WhatsApp.
- Mensajes de hasta 400 caracteres.
- No guarda sus datos. Evite escribir datos personales.
